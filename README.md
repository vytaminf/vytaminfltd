# VytaminF Ltd Website V3

Inspired by the structural energy of premium prop-trading / research websites, but written and designed uniquely for VytaminF Ltd.

## Replace your existing GitHub Pages site

1. Open your existing `vytaminfltd` repository.
2. Click **Add file** -> **Upload files**.
3. Upload:
   - `index.html`
   - `styles.css`
   - `script.js`
4. Commit directly to `main`.
5. Wait 1–3 minutes for GitHub Pages to redeploy.
6. Hard refresh the live website with `Ctrl + F5`.

No GitHub Pages settings need to change.
